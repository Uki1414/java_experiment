# java_experiment — My Painter

「情報メディア実験Ａ」で取り組んだ、Java による GUI プログラミングの実験リポジトリです。
Swing / AWT を用いた描画アプリケーション **My Painter** を、図形の表示からマウス操作、選択・編集、ファイル保存へと段階的に拡張しています。

リポジトリ直下にアプリケーションのソースコードと、GUI・イベント処理の練習コードを収録しています。

## 主な機能

- **図形描画**：矩形、楕円、角丸矩形、十一角形をマウスのドラッグで作成
- **見た目の変更**：塗りつぶし色・線色・線幅、破線、影の設定
- **図形編集**：単一選択・範囲による複数選択、移動、ハンドルによるサイズ変更、削除
- **重なり順の変更**：選択したオブジェクトを最前面・最背面へ移動
- **コピー／切り取り／貼り付け**：アプリ内のバッファを使ったオブジェクトの複製
- **文字入力・編集**：キャンバス上への文字配置、入力済み文字の編集、フォント・サイズ・太字・斜体・下線の設定
- **保存・読み込み**：描画オブジェクトをファイルに保存し、再編集

## 実行環境

- JDK（`java` と `javac` を使用）
- GUI を表示できるデスクトップ環境
- Git（リポジトリをクローンする場合）

外部ライブラリは不要です。Java 標準の Swing、AWT、Java 2D、入出力 API を使用しています。
Maven / Gradle の設定はなく、`javac` で直接コンパイルできます。

> リポジトリ直下のソースは JDK 26.0.1 でコンパイル確認済みです。`--release 8` を指定したコンパイルも通りますが、JDK 8 での実行と GUI 操作は未検証です。

## セットアップ・起動

```sh
git clone https://github.com/Uki1414/java_experiment.git
cd java_experiment
javac -encoding UTF-8 -d build *.java
java -cp build MyApplication
```

起動すると「My Painter」ウィンドウが表示されます。
リポジトリに含まれる既存の `.class` ファイルではなく、上記の手順でソースから生成したクラスを使用してください。

## 使い方

### 図形を描く

1. ツールバーから `Rectangle`、`Oval`、`RoundRect`、`Hendecagonal` のいずれかを選択します。
2. 白いキャンバス上でドラッグし、図形の大きさを指定します。
3. `Fill:` で塗りつぶし色、`Line:` で線色、`Width:` で線幅を変更します。

`Other Colors...` ではカラーダイアログから任意の色を選択できます。
`Dashed` で破線、`Shadow` で影を設定します。
これらの設定は選択中のオブジェクトと、以降に作成するオブジェクトに適用されます。

### 選択・移動・サイズ変更

- `Select` を選び、オブジェクトをクリックすると選択できます。
- キャンバスの空白からドラッグすると、選択範囲と交差する複数のオブジェクトを選択できます。
- 選択したオブジェクト上をドラッグすると移動できます。
- 選択時に表示される黒いハンドルをドラッグすると、図形のサイズを変更できます。
- `To Front` で最前面、`To Back` で最背面へ移動できます。

文字の表示サイズはフォントサイズで調整してください。

### 文字を入力・編集する

1. `Text` を選び、キャンバス上の配置したい位置をクリックします。
2. 入力欄に文字を入力し、`Enter` で確定します。入力欄からフォーカスを移した場合も確定します。
3. 入力済みの文字を `Text` モードでクリックすると、内容を編集できます。

`Esc` で入力・編集をキャンセルできます。
既存の文字を空にして確定すると、その文字オブジェクトを削除します。

`Font:`、`Size:`、`Bold`、`Italic`、`Underline` で文字の書式を変更できます。
サイズは選択肢のほか、1〜300 の整数を直接入力できます。文字色は `Line:` で指定します。
使用できるフォントは実行環境にインストールされているものです。

### キーボード操作

オブジェクトを選択し、キャンバスにフォーカスがある状態で使用します。

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| コピー | `Ctrl + C` | `Command + C` |
| 切り取り | `Ctrl + X` | `Command + X` |
| 貼り付け | `Ctrl + V` | `Command + V` |
| 削除 | `Delete` / `Backspace` | `Delete` / `Backspace` |

貼り付けたオブジェクトは、コピー元から右下へ 20 ピクセルずらして配置されます。
コピーはアプリ内のバッファを使用するため、他のアプリとのクリップボード共有には対応していません。

### 保存・読み込み

- `File > Save`：現在の描画データを指定したファイルに保存します。
- `File > Open`：保存したデータを読み込み、キャンバスの内容を置き換えます。

保存形式は Java オブジェクトのシリアライズです。PNG / JPEG などの画像形式ではありません。
拡張子は自動付与されないため、例えば `drawing.dat` のようにファイル名を指定してください。
クラスの構造を変更した場合、以前のバージョンで保存したファイルを読み込めないことがあります。

## 主要クラス

| クラス | 役割 |
| --- | --- |
| `MyApplication` | ウィンドウ、ツールバー、メニュー、イベントリスナーの設定 |
| `MyCanvas` | 描画領域とオブジェクトの再描画 |
| `MyDrawing` | 図形・文字に共通する位置、サイズ、描画属性、選択ハンドルの管理 |
| `MyRectangle` / `MyOval` / `MyRoundRect` / `MyHendecagonal` | 各図形の描画と当たり判定 |
| `MyTextBox` | 文字とフォント情報の管理・描画 |
| `State` / `StateManager` | 操作モードの切り替え、マウスイベントと各種設定の処理 |
| 各図形ボタン / `SelectButton` / `TextButton` | 描画・選択・文字入力モードの実装 |
| `Mediator` | オブジェクト一覧、選択、移動、重なり順、複製、保存・読み込みの管理 |
| `MyDashStroke` | 破線の描画設定 |

図形クラスの継承、イベントリスナー、State パターンによる操作モードの切り替え、Mediator によるオブジェクト管理を学べる構成です。

## 補足

- 起動直後は操作モードが未選択です。最初に描画ツールを選んでください。
- ツールバーが収まりきらない場合は、ウィンドウを横に広げてください。
- Undo / Redo と画像ファイルへの書き出しは未実装です。
- 終了時に未保存データの確認は行われません。必要なデータは終了前に保存してください。
- 保存・読み込みのエラー詳細は、起動したターミナルに出力されます。
